# RepoSense

A full-stack web application for analyzing GitHub repository activity and assessing software project health.

## Technology Stack

- Java 21
- Spring Boot
- Angular
- MySQL
- Git and GitHub
- GitHub REST API
- Maven

## Core Features

- GitHub repository metadata analysis
- Commit activity analysis
- Contributor statistics
- Issues and pull request analysis
- Repository health score
- Interactive analytics dashboard
- Repository analysis history
